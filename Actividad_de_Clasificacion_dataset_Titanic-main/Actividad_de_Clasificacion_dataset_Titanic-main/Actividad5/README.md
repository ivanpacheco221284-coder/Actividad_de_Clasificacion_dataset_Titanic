# Instrucciones adicionales

- Ejecuta en tu entorno local o Colab. En Colab puedes subir el repo y ejecutar el notebook `fuentes/entrena.ipynb`.
- MLflow: para ver los runs, ejecuta `mlflow ui` en la raíz del repo y abre http://localhost:5000
- Los artefactos y modelos quedan en `mlruns/` y también se registran como artefactos en cada run.
